
# 字体、字号与样式规范

## 1. 字体家族
- 中文首选：PingFang SC
- Windows 中文：Microsoft YaHei
- 英文与数字：Inter
- 回退：Noto Sans SC, sans-serif

推荐 CSS：
```css
font-family: Inter, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif;
```

## 2. 字号层级
| 层级 | 用途 | 字号/行高 | 字重 |
|---|---|---:|---:|
| Display | 设计系统页大标题 | 32 / 40 | 600 |
| H1 | 页面标题 | 24 / 32 | 600 |
| H2 | 卡片/区块标题 | 20 / 28 | 600 |
| H3 | 小节标题 | 18 / 26 | 600 |
| H4 | 次级标题 | 16 / 24 | 600 |
| Body L | 正文强调 | 16 / 24 | 400 |
| Body | 常规正文 | 14 / 22 | 400 |
| Body S | 辅助说明 | 13 / 20 | 400 |
| Caption | 标签、脚注 | 12 / 18 | 400 |
| Button | 按钮文字 | 14 / 20 | 500 |
| Code | 代码/ID | 12 / 18 | 500 / Monospace |

## 3. 色彩规范
### 中性色
- N0：#FFFFFF
- N1：#F6F8FC 页面背景
- N2：#EEF2F7 浅分割背景
- N3：#E5EAF3 边框/分割线
- N6：#6B7280 辅助文字
- N8：#1F2A37 主文字

### 主色
- Primary：#1677FF
- Primary Weak：#E8F1FF

### 语义色
- Success：#52C41A
- Warning：#FAAD14
- Danger：#FF4D4F
- Info：#13C2C2

## 4. 组件样式
- 卡片圆角：16 px
- 输入框/按钮圆角：8 px
- 轻阴影：0 2px 6px rgba(16,24,40,.06)
- 常规阴影：0 4px 12px rgba(16,24,40,.08)
- 页面内容区卡片边框：1px solid #E5EAF3

## 5. 状态标签
- 成功：浅绿底 + 绿文字
- 警告：浅橙底 + 橙文字
- 错误：浅红底 + 红文字
- 信息：浅蓝/浅青底 + 对应文字
