
# UI 布局、交互与开发还原说明

## 1. 全局壳层（基于已确认母版）
- 左侧导航宽度：232 px
- 顶部全局栏高度：72 px
- 页面内容左右内边距：24 px
- 内容卡片之间栅格间距：16 px / 20 px
- 右侧辅助栏宽度：280 px（页面）
- 主内容区优先使用 12 栅格响应布局

## 2. 页面结构
### 列表页
- 顶部：页面标题 + 说明 / 动作按钮
- 其次：筛选区（搜索、下拉、状态筛选）
- 主体：卡片列表或表格
- 右侧：帮助、快捷操作、空状态辅助区

### 详情页
- 顶部：标题 + 状态 + 关键动作
- 其次：摘要 KPI / 关键元信息
- 主体：多卡片分组展示
- 右侧：时间线 / 成员 / 辅助说明 / 快捷入口

### 工作流页（如新建发布单）
- 左侧：步骤导航
- 中间：大表单分组
- 右侧：风险提示、填写指引、模板快捷入口
- 底部：主按钮区（取消 / 暂存 / 下一步）

### 沉浸页（如拓扑画布）
- 顶部：返回、上下文、画布动作按钮
- 中间：画布区域
- 右侧：属性抽屉常驻
- 底部：日志 / 校验结果 / 变更记录 Tab

## 3. 弹窗规范
- 标准弹窗宽度：480 / 560 / 720 px
- 结构：标题区 / 内容区 / 底部按钮区
- 标题区高度建议：56 px
- 底部按钮区固定对齐右侧，主按钮在最右
- 高风险确认弹窗主按钮使用红色 Danger

## 4. 抽屉规范
- 宽度：360 / 420 / 480 / 560 px
- 右侧滑出，保留页面上下文
- 结构：标题区 / 内容区 / 底部操作区
- 用于快速详情、筛选、配置和日志查看

## 5. 交互规则
- 顶部全局栏不放复杂业务动作
- 页面主动作放标题区右侧
- 列表行操作使用链接/文本按钮 + 更多菜单
- 复杂流程不塞弹窗，使用独立页面
- 轻量详情、筛选、日志优先用抽屉
- 高风险动作必须二次确认

## 6. 间距体系（8px 基准）
- 4 px：图标与最小元素微距
- 8 px：按钮内边距、表单微距
- 12 px：标题与内容间距
- 16 px：卡片内部标准间距
- 24 px：模块与模块间距
- 32 px：页面级大区块间距
