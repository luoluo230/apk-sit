
# 图标切图规范

## 1. 交付内容
- 每个图标单独输出一个文件，不使用整张雪碧图。
- 源文件：`icons/svg/*.svg`
- 位图切图：`icons/png/24/*.png`、`icons/png/48/*.png`
- 清单：`icon_manifest.json`

## 2. 规格
- 标准设计画板：24 × 24 px
- 默认导出尺寸：24 px、48 px
- 线性图标默认描边：1.8 px
- 端点与拐角：round
- 默认安全区：图标外圈至少保留 2 px 空白
- 背景：透明

## 3. 命名规范
`分类_语义名称` 或 `nav_xxx / action_xxx / status_xxx / topology_xxx`

例如：
- `nav_project_list.svg`
- `action_download.png`
- `status_warning.svg`

## 4. 使用方式
- 页面导航、按钮、卡片、表格操作区优先使用 SVG。
- 若客户端或旧浏览器不方便直接使用 SVG，可回退 24px PNG。
- 高密屏推荐直接使用 SVG；如必须位图，优先使用 48px PNG 缩放到 24px。

## 5. 颜色使用
- 导航/常规操作图标：主蓝 `#1677FF`
- 全局弱操作图标：中性灰 `#6B7280`
- 危险操作：红色 `#FF4D4F`
- 状态语义：成功绿、警告橙、错误红、信息青

## 6. 开发注意事项
- 禁止自行改粗细、圆角、比例。
- 同一区域图标尺寸保持统一。
- 按钮内图标建议与文字基线垂直居中，图文间距 6~8 px。
- 表格操作列图标建议 16~18 px；导航/卡片图标建议 20~24 px。
