# P19 发布单详情 — 设计规格

| 项 | 值 |
|---|---|
| 设计参考 | 用户截图 2026-07-06 + P17 表单视觉体系 |
| 运行 URL | `/admin/projects/{project_id}/release-orders/{order_id}` |
| 模板 | `release_order_detail.html` |
| 样式 | `release_order_detail.css` |
| 脚本 | `project_delivery.js` → `loadOrderDetail()` |

## 页面分区（P0 占比）

| 区域 | 占比 | 内容 |
|------|------|------|
| 页头 | 全宽 | 标题 + 状态 pill + 下一步 Primary + 更多操作 |
| 元信息条 | 全宽 5 列 | 环境 / 版本 / 渠道平台 / 负责人 / 总体状态 |
| 进度条 | 全宽 3 段横排 | 准备 · 计划 · 执行（**禁止**竖排文字） |
| 问题焦点区 | 主区全宽 | 待处理问题（≤6 条分组），危险/就绪 tone |
| 详情页签 | 主区单面板 | **发布计划** · **构建产物** · **环境与预检** · **审批发布**（同时只展示一个） |
| 右栏 | ~300px sticky | 修复指引 · 风险提示 · 事件时间线 |

## 交互清单

| 动作 | 行为 |
|------|------|
| 下一步 Primary | 按状态跳转编辑 / 构建 / 预检 / 发布 |
| 更多操作 | 下拉次要 API 操作 |
| 待处理问题卡片 | 每项「去处理」跳转构建历史 / 管线配置 / 拓扑 / 编辑 |
| 修复指引按钮 | 编辑计划、构建历史、配置管线、重新预检 |
| 预检清单 | 5 项 ✓/! + 去处理链接 |
| 确认弹窗 | 发布 / 回滚 / 取消需填写原因 |

## 诊断合并规则

预检 raw 字段（apk_url 等）**不得逐条展示**；合并为 ≤6 类：代码热更 / APK / 资源 / 配置 / 网络 / Runtime。
