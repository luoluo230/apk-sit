# 项目版本管理新版 UI 设计规格

更新时间：2026-06-11

## 1. 模块范围

- 页面：`/admin/projects/{project_id}/versions`
- 目标：按新版设计稿重构项目版本管理工作台 UI
- 约束：功能不减，继续复用现有版本、VersionCode、下载、测试设备、GM 发版与构建逻辑

## 2. 设计真源

- 设计图：`docs/design_assets/project-version-management-redesign-reference.png`

## 3. 页面结构

### 3.1 一级布局

- 左侧深色全局导航栏
- 顶部白色工具栏
- 主体三栏
  - 左：项目与环境树
  - 中：版本主工作区
  - 右：项目说明 / 拓扑 / 快捷操作 / 最新动态
- 底部操作面板
  - 新建拓扑图
  - 渠道管理
  - 新建版本组
  - 编辑 VersionCode
  - GM 发版向导入口
  - 扫码下载

### 3.2 中央主工作区

- 标题：项目版本管理 / 项目名 / 运行中
- KPI 卡片 7 个
- 顶部标签
  - 版本总览
  - 渠道管理
  - 构建历史
  - 测试设备
  - 下载中心
- 工具条
  - 当前渠道提示
  - Android / iOS 快捷筛选
  - 版本号 / VersionCode 搜索
  - 阶段筛选
  - 状态筛选
  - 新建版本组按钮
- 版本组列表区

## 4. 11 维实现清单

### 4.1 布局与占比

- 左侧全局导航固定窄栏
- 左侧项目树为浅色卡片
- 中央内容占主宽度
- 右侧信息栏固定窄列
- 底部面板为 6 列卡片

### 4.2 间距

- 外层卡片统一大圆角
- 主区与侧区间距 14px 左右
- KPI 卡片内部为图标 + 数值双列结构

### 4.3 字体

- 主标题粗体深蓝
- 二级标题中粗
- 标签、说明文案偏小

### 4.4 字号层级

- 主标题 16-18px
- KPI 数值 24px+
- 面板标题 14px
- 表格正文 12-13px

### 4.5 排版

- 中央版本表格横向完整显示
- 右侧信息卡以键值对形式展示
- 底部面板每张卡独立操作

### 4.6 色彩与风格

- 左侧导航深蓝渐变
- 主区背景浅蓝灰
- 卡片白底 + 淡蓝边框
- 主按钮亮蓝渐变
- 状态色保持语义分层

### 4.7 图标

- 导航、KPI、快捷操作、按钮都有图标位
- 图标风格统一为线性 Font Awesome

### 4.8 适配

- 1680 以下底部面板收成 3 列
- 1360 以下右侧信息栏下沉
- 1120 以下左导航折叠，主体转单列

### 4.9 交互态

- 左导航 hover
- 当前菜单激活态
- 顶部标签激活态
- 平台筛选按钮激活态
- 卡片 hover 轻微提亮

### 4.10 反馈态

- 无版本空态
- 下载区无安装包空态
- 测试设备入口态
- 版本列表加载后刷新摘要

### 4.11 文案

- 页面标题、标签、卡片名称按设计稿中文为主
- 核心业务字段保留英文补充，如 `VersionCode`

## 5. 功能映射

- 版本总览：复用现有 `renderChannelsView()`
- 新建版本组：复用 `saveVersion()`
- 编辑 VersionCode：复用 `saveVersionCodeModal()`
- 渠道管理：复用原有添加 / 移除渠道逻辑
- 测试设备：复用 `openDeviceManageModal()`
- 下载二维码：复用 `window._showQR()`
- GM 发版：跳转 `/admin/gm-ops`
- 拓扑：跳转 `/admin/ops-platform`

## 6. 验收重点

- 页面必须渲染新版三栏 + 底部六面板结构
- 版本列表功能不能断
- 新建版本组按钮可继续创建版本
- VersionCode 快速编辑可继续保存
- 渠道增删、测试设备、下载二维码、GM/运维跳转都必须可用
- 不允许只做静态样式，不接现有真实功能
