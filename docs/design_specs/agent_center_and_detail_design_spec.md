# Agent 管理中心与详情页设计实现文档

## 模块信息

- 模块名称：`Agent 管理中心` / `Agent 详情页`
- 页面路由：
  - `/admin/ops-platform/agent-control`
  - `/admin/ops-platform/agent-detail`
- 设计图来源：当前 Codex 线程中的两张设计截图
- 设计资源预留：
  - `docs/design_assets/agent-center.png`
  - `docs/design_assets/agent-detail.png`

## 设计硬约束

- 页面按设计图 1:1 实现，不接受“风格接近”。
- 验收以有数据主态为准，不以空态代替主态。
- 不沿用与设计冲突的旧页面壳、旧容器结构、旧视觉风格。
- 页面、脚本、样式、文档不得出现乱码。
- 改动完成后必须核对真实运行入口、运行进程、模板版本号、静态资源版本号。

## Agent 管理中心

### 页面结构

- 左侧导航
- 顶部工具栏
- 面包屑
- 标题与副标题
- 顶部 3 个主操作按钮
- 4 张 KPI 卡片
- 筛选工具栏
- 批量操作栏
- 双列 Agent 卡片区
- 底部分页器

### 视觉要求

- 左侧导航固定宽度，分组标题、图标、激活态与设计图一致。
- 顶部按钮区的圆角、间距、图标、层级与设计图一致。
- KPI 卡片使用浅边框、轻阴影、大圆角、左侧图标块。
- 筛选栏保持单行优先，窄屏下自然换行。
- Agent 卡片必须展示：
  - 勾选框
  - 设备图标
  - 标题
  - 状态标签
  - IP
  - 最后心跳
  - CPU / MEM / DISK 指标胶囊
  - 服务汇总
  - 查看详情 / 编辑 / 探测
- 分页器位置、按钮尺寸、当前页高亮与设计图一致。

### 功能要求

- 按状态筛选
- 按关键字搜索
- 按服务状态筛选
- 按活跃窗口筛选
- 卡片 / 列表视图切换
- 批量选择
- 批量探测
- 批量重启服务
- 批量绑定服务入口
- 清理过期 Agent

## Agent 详情页

### 页面结构

- 左侧导航
- 深色顶栏
- 面包屑
- 标题区与状态
- 元信息行
- 顶部操作按钮
- 标签页
- 5 张摘要卡
- 中部双栏：
  - 服务与进程
  - 监控指标
- 底部三栏：
  - 近期任务
  - 告警事件
  - 配置信息
- 底部系统信息栏

### 视觉要求

- 顶部 5 张摘要卡高度一致。
- Tab 激活态使用细下划线。
- 服务表格列宽稳定，数字列右对齐，状态标签风格一致。
- 监控图区域使用与设计图一致的留白和浅虚线空态。
- 顶栏、标题区、操作按钮、表格、底栏与设计图同层级。

### 功能要求

- 概览页优先完整可用
- 设备信息、服务与进程、监控指标、任务历史、操作日志、配置管理、告警事件、审计日志都接真实数据
- 编辑、重启 Agent、更多操作入口可用
- 一个 Agent 可以聚合并展示多个服务

## 数据模型约束

- 页面语义必须是：`1 个 Agent -> 管理多个服务 / 游戏服务器`
- 不允许把兼容层里的单服务条目直接当最终 Agent 卡片展示
- 管理中心列表和详情页必须都使用逻辑 Agent 聚合后的数据口径

## 本次任务暴露出的高频偏差

- 不能只改内部 helper，不切真正页面入口。
- 不能只做骨架，不做有数据主态卡片区。
- 不能用占位字符代替正式图标风格。
- 不能跳过运行中服务进程、模板版本号、静态资源版本号核对。
- 不能在未完成截图级差异审计前宣称“已按设计图完成”。
