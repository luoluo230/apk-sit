# Agent 管理中心与详情页设计实现文档

## 模块信息

- 模块名称：`Agent 管理中心` / `Agent 详情页`
- 页面路由：
  - `/admin/ops-platform/agent-control`
  - `/admin/ops-platform/agent-detail`
- 设计源：当前线程中的两张设计截图
- 设计资源预留：
  - `docs/design_assets/agent-center.png`
  - `docs/design_assets/agent-detail.png`

## 硬性目标

- 页面必须按设计图 1:1 实现，不接受“接近”或“风格类似”。
- 验收以浏览器运行态为准，不以源码或空态为准。
- 运行态不得出现乱码、混合编码、占位字符、旧壳残留、错误入口。
- 任何视觉差异未清零前，不得声称“已按设计图完成”。

## 设计拆解清单

### Agent 管理中心

- 左侧导航宽度、分组标题、激活态底色、图标、页脚折叠菜单
- 顶部面包屑、通知/帮助/头像区
- 标题、图标、说明文案
- 顶部三枚操作按钮：新建设备 Agent / 一键探测测试 / 批量修复并探测
- 四张 KPI 卡片：图标风格、数字字号、说明文案、圆角和阴影
- 筛选栏：状态、搜索、服务状态、活跃窗口、应用筛选、重置、视图切换
- 批量操作栏：已选择、批量探测、批量重启、批量绑定服务、更多操作、清理过期 Agent、自动刷新提示
- 主内容主态：双列 Agent 卡片，卡片信息与设计一致
- 分页器：位置、尺寸、激活态、每页条数选择器

### Agent 详情页

- 深色顶栏、左侧导航、面包屑
- 标题行：Agent 名称、状态、辅助图标、右上按钮组
- 元信息行：ID / 分组 / 环境 / 版本 / 最近心跳 / 安装时间
- Tab 栏：概览 / 设备信息 / 服务与进程 / 监控指标 / 任务历史 / 操作日志 / 配置管理 / 告警事件 / 审计日志
- 概览页五张摘要卡：状态、系统资源、连接信息、服务健康、告警事件
- 中部双栏：服务与进程表 + 监控图表
- 底部三栏：近期任务 / 告警事件 / 配置信息
- 底部系统信息栏

## 数据模型约束

- 页面语义必须是：`1 个 Agent -> 管理多个服务 / 游戏服务器`。
- Agent 列表与详情页都必须基于逻辑 Agent 聚合结果展示。
- 不允许把兼容层中的单服务记录直接当成最终 Agent 卡片。

## 本轮实现要求

- 重写受污染模板和脚本为干净 UTF-8。
- 管理中心与详情页都使用最新静态资源版本号，避免旧缓存命中。
- 改动后必须核对真实运行入口、服务进程和最终浏览器结果。
