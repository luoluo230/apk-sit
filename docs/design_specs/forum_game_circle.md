# 游戏圈

论坛玩家页按游戏圈的信息架构组织，使用仓库自有图标，不使用微信素材，也不套管理台壳。

## 页面

- 游戏头：图标、名称、进入圈子
- 一条动态流：官方置顶和玩家帖混排
- 切换：最新、推荐。推荐按点赞数，置顶仍在前面
- 话题：帖子上的话题，点进同一话题
- 帖子：图文、点赞、评论
- 发帖：标题、话题、正文、本地图片地址
- 福利：动态流里的一张卡片，链到原福利详情，不再做另一套首页

身份用「官方」和「玩家」区分。官方来自现有 `is_official`。

## 接口

- `GET /forum` 渲染动态流
- `GET /forum/<id>` 渲染帖子
- `POST /forum/create` 发帖，可带 `topic` 和 `media_urls`
- `POST /forum/<id>/like` 点赞或取消
- `POST /forum/<id>/comment` 评论，保持原接口

玩家站其它产品页不在这一页的范围内。
