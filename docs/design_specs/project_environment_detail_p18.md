## 交付线卡片（2026-07-07 用户验收 · 窄小卡片）

> **冻结风格。** 细则见 `.cursor/rules/delivery-matrix-compact-cards.mdc`

### 布局

- 按渠道分组；组内 **`repeat(auto-fill, minmax(200px, 220px))`** 多列小卡片，**禁止**表格/列表条/双列撑满
- 单卡 max-width **220px**；无 min-height 撑高

### 结构

- 头：平台图标 **44×44**（SVG 26×26）+ 名称 + 状态徽章
- 一行 status hint（ellipsis）
- 字段：版本 / Bundle / 拓扑（标签+值同行）
- 底：构建 + 发版（不同语义底色）

### 状态色

| 状态 | 卡片 | 图标底 | hint |
|------|------|--------|------|
| 已配置 | 浅绿渐变 + 绿边框/左线 | `#e8f8e8` | `#389e0d` |
| 未配置 | 浅橙渐变 + 橙边框/左线 | `#fff7e6` | `#d48806` |

### 按钮

- **构建** `.matrix-btn.build`：蓝底（未配置卡橙底）
- **发版** `.matrix-btn.release`：绿底（未配置卡浅红底）

## 验收

- [x] 无 KPI 摘要区
- [x] 窄小卡片网格（非表格/列表）
- [x] 已配置/未配置卡片色区分
- [x] 构建/发版按钮不同底色
- [x] 平台图标 44px（用户确认尺寸 OK）
